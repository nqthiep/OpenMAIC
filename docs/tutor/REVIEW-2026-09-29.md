## 2. Phát hiện thêm trong lúc sửa

- `widgetConfig` được nhét nguyên (JSON string) vào prompt sinh action (`packages/@openmaic/generation/src/scene-generator.ts:1725-1740`) → phải **nhẹ**, kèm `frameOutline` để LLM thầy biết frame nào cần nhảy; frame đầy đủ để ở khối `walkthrough-data` (ADR 0005 §2).
- `extractInteractiveElements` bỏ `<script>`/`<style>` → id `#wt-*` phải nằm trong DOM tĩnh (ARCHITECTURE §5).
- `OutlineConstraints` không liệt kê được giá trị của `widgetOutline` → `walkthroughId` hợp lệ đi qua `SKILL.md` + test đồng bộ (ADR 0006 §4).
- `noConsecutiveSameWidgetType` sẽ cấm hai walkthrough liền nhau (chỉ có một widget type) → bỏ cờ này.
- Snippet là include tĩnh, `SnippetId` là union đóng, tốn token cho mọi khoá học; whiteboard action (`wb_draw_*`) nằm ở tầng chat/agent → cookbook chuyển thành `references/` của skill (còn spike S2).
- KaTeX auto-render của `postProcessInteractiveHtml` đặt `trust: true` → chuỗi do LLM cấp không được vào vùng KaTeX; schema `input` chặn ký tự đặc biệt.
- Đổi `dsl`/`generation` là đổi hai package publish → bump version (`check:package-versions`).

# Vòng 4 (2026-09-30): user chốt ba câu hỏi; "Manim là hướng chính"
