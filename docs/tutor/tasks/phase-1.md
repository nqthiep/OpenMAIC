### 1a-01 · Engine: `generateSteps` và `steps`

| Trường | Giá trị |
| --- | --- |
| Cấp | W |
| Cỡ | S |
| Phụ thuộc | — |
| Sở hữu | `lib/tutor/engine/types.ts`, `lib/tutor/engine/generate.ts`, `tests/tutor/engine/generate.test.ts` |
| Đọc | [../decisions/0001-step-engine-immutable.md](../decisions/0001-step-engine-immutable.md) (khối Decision); ADR 0006 quyết định 7 (dòng `steps`); [README](README.md) §5 D1 |

**Làm**
1. `types.ts`: chép đúng khối TS của ADR 0001 (`HighlightKind`, `FrameMeta`, `Frame`, `DEFAULT_MAX_FRAMES = 500`, `DEFAULT_MAX_STEPS = 10_000`, `Emit`). Thêm:
   ```ts
   export interface RunContext { readonly locale: string }
   export interface StepSource<I, S> {
     run(input: Readonly<I>, emit: Emit<S>, tick: () => void, ctx: RunContext): void
     readonly maxFrames: number
     readonly maxSteps?: number
   }
   ```
2. `generate.ts`: `generateSteps(input, run, options?)` theo ADR 0001.
   - `input` được `structuredClone` rồi deep-freeze trước khi đưa cho `run`.
   - `emit(state, meta)`:
     - đã có `maxFrames` frame thì ném `RangeError`;
     - `state` có hàm, `Map`, `Set`, `undefined` hoặc số không hữu hạn thì ném `TypeError`;
     - clone + deep-freeze `state` và `meta`; gán `index` = số frame hiện có.
   - `tick()`: tăng bộ đếm; vượt `maxSteps` thì ném `RangeError`.
   - `options.maxFrames > DEFAULT_MAX_FRAMES` thì ném `RangeError` (lỗi tác giả).
   - Trả mảng đã freeze.
3. `steps(entry: StepSource<I,S>, input: I, opts: { locale: string })` = `generateSteps(input, (i, e, t) => entry.run(i, e, t, { locale: opts.locale }), { maxFrames: entry.maxFrames, maxSteps: entry.maxSteps })`.
4. Chạy được trong trình duyệt: không import module Node.

**Không làm:** import kiểu từ `lib/tutor/catalog`; dùng generator.

**Làm**
```ts
export const BASE_FRAME_MS = 1200                 // [Inference] chỉnh sau khi thử
export interface PlayerState { readonly index: number; readonly total: number; readonly isPlaying: boolean; readonly speed: number }
export interface Player {
  getState(): PlayerState
  subscribe(fn: (s: PlayerState) => void): () => void
  play(opts?: { restart?: boolean }): void   // đang phát: không làm gì. Ở frame cuối: restart → về 0 rồi phát; không restart → đứng yên
  pause(): void
  toggle(): void                              // nút Phát/Tạm dừng: ở frame cuối và đang dừng → về 0 rồi phát
  step(delta: 1 | -1): void                   // tạm dừng, đi một bước, kẹp [0, total-1]
  jump(index: number): void                   // số không nguyên → bỏ qua; kẹp [0, total-1]
  setSpeed(speed: number): void               // NaN → bỏ qua; kẹp [0.25, 2]
  setTotal(total: number): void               // đổi preset: dừng, kẹp index; total < 1 coi là 1
  reset(): void                               // về 0, dừng
  dispose(): void                             // huỷ timer, bỏ mọi subscriber
}
export function createPlayer(opts: { total: number; speed?: number;
  setTimer?: (fn: () => void, ms: number) => unknown; clearTimer?: (h: unknown) => void }): Player
```
- Khi phát, mỗi bước chờ `BASE_FRAME_MS / speed`, rồi tăng `index`; tới frame cuối thì tự dừng.
- `subscribe` chỉ được gọi khi trạng thái thật sự đổi. Mặc định `setTimer`/`clearTimer` dùng `setTimeout`/`clearTimeout`.

### 1a-05 · `InputSpec` và `parseInput`

| Trường | Giá trị |
| --- | --- |
| Cấp | W |
| Cỡ | S |
| Phụ thuộc | — |
| Sở hữu | `lib/tutor/input-spec.ts`, `tests/tutor/input-spec.test.ts` |
| Đọc | ADR 0006 quyết định 7 (khối `InputSpec`) và quyết định 8; [README](README.md) §5 D10 |

**Làm**
1. Kiểu `InputSpec` đúng 8 kind của ADR 0006.
2. `parseInput<I>(spec, raw): { ok: true; value: I } | { ok: false; issues: string[] }`:
   - `JSON.stringify(raw)` lỗi → `['not-json']`; dài > 2048 byte UTF-8 (đo bằng `TextEncoder`) → `['too-large']`;
   - tối đa 5 issue, dạng `đường-dẫn: lý-do` (ví dụ `values[3]: not-increasing`);
   - không ném lỗi với mọi kiểu đầu vào; `value` là bản sao.
3. Ngữ nghĩa từng kind:
   - `int`: số nguyên trong `range`;
   - `number`: hữu hạn, trong `range`, là bội của `step` tính từ `range[0]` (sai số 1e-9);
   - `enum`: `===` một phần tử của `values`;
   - `int-array`: độ dài trong `len`, mỗi phần tử nguyên trong `range`, `strictlyIncreasing` nếu có;
   - `string`: độ dài trong `len`, mọi ký tự thuộc `alphabet`;
   - `edge-list`: `{ n, edges: [from, to, weight?][] }`, `n` trong `nodes`, số cạnh trong `edges`, chỉ số trong `[0, n)`, `from ≠ to`, có `weight` khi và chỉ khi spec có `weight`;
   - `grid`: mảng chữ nhật, `rows`/`cols` trong miền, `cell: 'bit'` → 0 hoặc 1, `'int'` → trong `range`;
   - `record`: object thường; thiếu khoá → `k: missing`, khoá lạ → `k: unknown-key`; kiểm đệ quy.
4. Chạy được trong trình duyệt (iframe dùng ở 1d). Không dependency.

**Xong khi:** `pnpm vitest run tests/tutor/input-spec.test.ts` xanh. Test phủ:
- từng kind (hợp lệ, biên, sai);
- khoá lạ; `strictlyIncreasing`; JSON > 2048 byte;
- kiểu lạ (`null`, `undefined`, hàm, vòng tham chiếu) không ném lỗi.

### 1a-06 · Băm chuẩn hoá: `framesHash`, `contentHash`

| Trường | Giá trị |
| --- | --- |
| Cấp | W |
| Cỡ | S |
| Phụ thuộc | — |
| Sở hữu | `lib/tutor/catalog/hash.ts`, `tests/tutor/catalog/hash.test.ts` |
| Đọc | [../DATA-MODEL](../DATA-MODEL.md) §3 (dòng `entryRev`, `framesHash`, `contentHash`); ADR 0013 quyết định 6 |

**Làm**
1. `canonicalJSON(v)`:
   - khoá object sắp xếp đệ quy; mảng giữ thứ tự;
   - `-0` thành `0`;
   - số không hữu hạn, `undefined`, hàm, symbol, bigint thì ném `TypeError`.

3. `framesHash(frames)` = `hash16(frames)`.
4. `contentHash({ code, beatDefs, presets, problem })` = `hash16({ code, beatDefs, presets: presets.map(p => ({ id: p.id, input: p.input })), problem: problem ?? null })`.
5. Comment đầu file: chỉ dùng phía server, không import vào runtime iframe.
